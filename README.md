# Momentum

**Alternative Education Student Growth Platform**

Momentum is a completely offline student growth platform designed specifically for alternative education.

Instead of focusing on grades, Momentum documents student growth through:

- Career Interests
- Projects
- Driving Questions
- Milestones
- Community Partners
- Internships
- Reflections
- Strengths
- Teacher Notes
- Follow-Ups

## Goals

- Work completely offline
- Run from a single HTML file
- No installation required
- Automatically save student data locally
- Help teachers document authentic student growth

## Planned Features

- Dashboard
- Student Management
- Learning Journey
- Search
- Import / Export
- Student Portfolios
- Reports

## Technology

- HTML5
- CSS3
- Vanilla JavaScript
- Local Storage
